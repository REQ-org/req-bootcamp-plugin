REQ AI Bootcamp · Høsten 2026

Kurset, rett i Claude.

Kurspluginen gir deg timeplan, forarbeid, oppsummeringer og svar på vanlige spørsmål for alle ti øktene — alltid oppdatert, uten å lete i e-post eller dokumenter.

Ti tirsdager · 08:30 18. aug – 20. okt Sommerrogata 17 / Teams

Slik installerer du

01

Installer Claude Code

Last ned skrivebordsappen eller CLI-en fra claude.com/claude-code og logg inn med kurskontoen din.

02

Kjør to kommandoer

Åpne Claude Code og lim inn én linje om gangen:

claude
/plugin marketplace add mainquest-labs/req-bootcamp-plugin
/plugin install req-bootcamp-plugin@req-bootcamp-plugin
03

Prøv det

Kjør /kurs — eller bare spør:

«hva er forarbeidet til neste økt?» «hva skjedde i økt 3?» «vis timeplanen»

Bruker du Claude uten Claude Code?

I Claude-appen på Mac/Windows eller på claude.ai kobler du deg til kursserveren som en connector:

  1. Åpne Settings → Connectors
  2. Velg Add custom connector
  3. Navn: REQ Bootcamp — og lim inn denne adressen:
    https://req-bootcamp-plugin.vercel.app/api/mcp
  4. Klikk Add — ingen innlogging trengs, serveren er åpen.

Hva får du

/kurs

Én kommando som viser neste økt: dato, tema og forarbeidet du bør gjøre.

Skills

Gikk du glipp av en økt? bootcamp-recap henter oppsummeringen. prep-me-for-bootcamp gjør deg klar til neste.

Alltid oppdatert

Innholdet oppdateres etter hver økt. Kjør /plugin update i Claude Code for siste versjon.
