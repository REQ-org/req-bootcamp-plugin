# Økt 2 - Skills (25. aug 2026)

Ekte skills i praksis: Herman viser skills han bruker og hvordan han lager dem - og du bygger din egen minimale skill på en oppgave du gjør ofte.

## Forarbeid

1. **Installer Claude Code** (skrivebordsappen eller CLI): https://claude.com/claude-code
2. **Installer kursets plugin** - din første! Åpne Claude Code og kjør:
   ```
   /plugin marketplace add mainquest-labs/req-bootcamp-plugin
   /plugin install req-bootcamp-plugin@req-bootcamp-plugin
   ```
3. **Test den:** skriv `/kurs` - får du oversikt over økt 2, er alt klart.
4. **Ta med:** én tilbakevendende oppgave du gjør nesten hver uke, med ett ekte eksempel på input og ønsket output.

Sitter du fast? Ta det med ro - vi løser det sammen i starten av økten.
