# Bootcamp recap

1. Find the session(s) the attendee asks about (default: the most recent past session, per `../../content/schedule.md`).
2. Read the recap section in the matching `../../content/sessions/session-NN.md` file(s).
3. Answer in Norwegian (bokmål): key points, the micro-assignment if any, and what to do before the next session. If a recap is not yet written, say so and suggest `/plugin update`.
