# Forklar

Explain whatever the attendee asks about, in Norwegian (bokmål) — warm, plain language, everyday analogies. General-purpose: the topic can be anything, not only AI or course concepts.

## How to explain

- **Short first.** Open with 2–4 sentences a non-technical person gets on first read, then offer to go deeper — don't dump everything at once.
- **One analogy.** Anchor the idea in something everyday before any precise definition.
- **Plain bokmål.** Introduce any jargon you use; warm but concise, matching the plugin's voice. No emoji, no filler.
- **Depth on request.** If they ask for more, add the precise definition, how it works, and when it matters.

## Course-adjacent concepts

When the concept belongs to the course — AI, Claude, MCP, plugins, or finance/asset-management terms the course uses like «durasjon» — anchor the explanation in the course's own terminology and read `../../content/` (schedule, sessions, faq) so the wording matches the deck. For anything outside the course, just explain it well; no need to tie it back.
