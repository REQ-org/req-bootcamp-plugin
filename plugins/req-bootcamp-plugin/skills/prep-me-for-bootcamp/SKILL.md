# Prep me for bootcamp

1. Find today's date, then find the **next** session in `../../content/schedule.md`.
2. Read that session's file in `../../content/sessions/` (e.g. `session-02.md`) for pre-work and details.
3. Answer in Norwegian (bokmål), warm but concise: date, topic, the pre-work as a short checklist, and one sentence on why this session matters. If the attendee missed the previous session, point them to `bootcamp-recap`.
